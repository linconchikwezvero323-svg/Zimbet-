# ZimBet Monorepo

Mobile-first betting platform for Zimbabwe.

## Structure
- `backend/`: Node.js Express API with SQLite database.
- `frontend/`: React + Vite + PWA frontend.
- `design/`: Brand identity, logo concepts, and UI mockups.

## Project Goal
Fast deposits and withdrawals via EcoCash and InnBucks, competitive odds, and a low-data mobile experience for Zimbabwean sports fans.
